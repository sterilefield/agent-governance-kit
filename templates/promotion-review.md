# Promotion review

| Field | Value |
|---|---|
| Agent | |
| From → to | e.g. L1 → L2 |
| Days at current level | (≥ 30) |
| Actions at current level | (≥ 20) |
| Critical incidents | (must be 0) |
| Eval suite run | date, tool, pass rate |
| Injection test set | pass / fail, number of cases |
| Orchestrator review | notes |
| Owner decision | Promote · Hold · Demote, with reason |

Any R3/R4 incident after promotion demotes the agent automatically.
