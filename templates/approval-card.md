# Approval card

| Field | Value |
|---|---|
| Card ID | AC-YYYYMMDD-NN |
| Agent and level | e.g. reminder-assistant, L2 |
| Risk class | R3 or R4 |
| Exact action | The literal command, message text or change, not a summary |
| Targets | Who or what is affected, and how many |
| Reason | Why now |
| Reversible? | Yes, and how / No |
| Rollback plan | What we do if it goes wrong |
| Expires | Approval is void after this time |

**Decision:** Approve · Reject · Ask for changes
**Approver:** name, from a registered device
**Time:**

> Approve exactly what is written. If the action changes, a new card is needed.
